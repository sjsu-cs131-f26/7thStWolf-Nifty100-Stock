# Cron Entry

Due to midterm and timing conflict, we didn't have three days to run the script.

If we wanted to run it daily, we would have used a cron of "30 10 * * *" to run it at 10.30 Am Every day.

However, we didn't have the time so we used a cron of "*/1 * * * *" to make it run every minute.

The Cron code of * * * * * represents minute, hour, day, month and Day of the week respectively.
